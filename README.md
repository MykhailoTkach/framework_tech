# ChurnGuard

ChurnGuard прогнозує відтік клієнтів телекому на основі Random Forest та ROC-аналізу. Підтримує генерацію синтетичних даних, навчання моделі, таблицю клієнтів з прогнозами, логи та звіти.

## Як працює

1. Генерація або завантаження датасету клієнтів
2. Препроцесинг (LabelEncoder, StandardScaler, SimpleImputer)
3. Навчання Random Forest (train/test split 80/20)
4. Метрики: Accuracy, Precision, Recall, F1, ROC AUC
5. Прогноз ймовірності відтоку для кожного клієнта
6. Відображення результатів: ROC-крива, матриця плутанини, таблиця клієнтів

## Встановлення

Вимоги: Python 3.10+

### Варіант A — PyCharm (рекомендовано)

1. Відкрий папку проєкту у PyCharm: `File → Open`
2. PyCharm запропонує створити віртуальне середовище — натисни **OK** (`.venv` створюється автоматично, вручну нічого робити не треба)
3. Якщо не запропонував — зайди в `File → Settings → Project → Python Interpreter → Add Interpreter → Virtualenv → OK`
4. Відкрий термінал у PyCharm (вкладка **Terminal** внизу) і виконай:

```
pip install -r requirements.txt
```

5. PyCharm підхопить встановлені бібліотеки автоматично

### Варіант B — звичайний термінал

```
pip install -r requirements.txt
```

## Запуск

```
python app.py
```

Відкрити: http://127.0.0.1:5000

## Використання

1. **Головна** — вкажи кількість клієнтів → натисни *Згенерувати* → *Навчити*
2. **Результати** — ROC-крива, матриця плутанини, метрики моделі
3. **Клієнти** — таблиця всіх клієнтів з ймовірністю відтоку, фільтрація та пошук
4. **Прогноз** — введи параметри нового клієнта → отримай ймовірність відтоку та рівень ризику
5. **Лог** — журнал подій додатку в реальному часі

## Результати

- Звіти: `reports/`
- Логи: `logs/churn.log`
- Датасет: `data/customers.csv`
